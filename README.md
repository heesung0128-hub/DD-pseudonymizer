# 개인정보 가명처리 도우미

교사가 개인정보가 든 엑셀·CSV를 AI에 넣기 전에 **가명(토큰)으로 바꾸고**, AI가 준 결과를 **원래 값으로 되돌리는** 로컬 전용 웹앱입니다.

## 시작하기
`index.html` 을 더블클릭해 최신 Chrome·Edge·Safari·Firefox 로 엽니다. 설치도 인터넷도 필요 없어요.
(파일이 수정되면 보안 검사에 걸려 멈춰요. 받은 그대로 쓰세요.)

## 사용법 (3단계)
**① 불러오기** — 엑셀/CSV를 끌어다 놓기 → 시트·머리글 행 확인 → 다음.

**② 선택·내보내기**
1. 열마다 `유지 / 토큰화 / 삭제` 선택. “추천대로 토큰화” 버튼으로 이름·학번·연락처 등을 한 번에.
2. 일부만 바꾸려면 열 머리글·행 번호를 누르거나 칸을 끌어서 선택(Ctrl/Shift로 여러 개).
3. 비고 속 이름은 “문장 속에서도 찾기”로 같은 토큰으로 바뀌어요. **바뀔 목록을 확인**해야 내보낼 수 있어요.
4. 노란 경고(전화번호·주민번호 모양, `[[...]]` 충돌)를 확인.
5. 표 저장(.xlsx/.csv) 또는 **“지시문 + 표 복사”** 후 AI 채팅에 붙여넣기.
6. **키 파일 저장**: 비밀번호를 두 번 입력. ⚠ 비밀번호를 잃으면 복원할 수 없어요.

**③ 복원** — 키 파일 + 비밀번호로 열기 → AI 답변(붙여넣기 또는 파일) 넣기 → “복원하기”. 복원한 토큰 수, 키에 없는 토큰, 변형 의심 토큰이 보고돼요. 같은 형식으로 복사·저장할 수 있어요.

작업을 마치면 오른쪽 위 **모두 지우기**를 누르세요.

## 알아둘 점
- 토큰 모양은 `[[이름_001]]`. 같은 값은 항상 같은 토큰. 키 파일 이름과 화면에 **키 ID** 가 있어요. 복원할 때 같은 ID인지 확인하세요(다른 키로 복원하면 엉뚱한 값이 들어갈 수 있어요).
- 문장 속 이름은 **성까지 똑같이 쓴 경우만** 찾아요. 이름만 쓴 경우(“하늘이”)는 “직접 추가할 단어”에 적으세요.
- 토큰화하지 않은 열(반·성별·점수 등)의 조합으로 사람이 짐작될 수 있어요. 내보내기 전 경고를 꼭 읽어 주세요.
- 병합 셀은 같은 값으로 채워 읽어요. 머리글 위쪽(제목) 행은 가져오지 않아요. 복원한 .xlsx 는 글꼴·색 같은 서식이 단순해질 수 있어요.
- AI 답변의 토큰이 `[[이름_01]]`, `[이름_001]` 처럼 바뀌면 “변형 의심”으로 알려 줘요. 체크박스를 켜면 키와 정확히 대응되는 것만 함께 복원해요.

## 보안 설계
- **단일 파일**: SheetJS 0.20.3(Apache-2.0)을 파일 안에 내장. CDN·외부 글꼴·외부 요청 없음. (파일 안의 `http://…` 글자는 엑셀 XML 이름표일 뿐 접속하지 않아요.)
- **CSP**: `connect-src 'none'`, `default-src 'none'`, 스크립트·스타일은 파일 안 코드의 해시만 허용. 네트워크 요청은 브라우저가 차단해요.
- **저장 없음**: 원본·대응표·비밀번호는 메모리에만 있고 localStorage/IndexedDB/쿠키를 쓰지 않아요. 분석 도구·로그 없음.
- **암호화**: Web Crypto, PBKDF2(SHA-256, 600,000회) → AES-GCM 256. salt·IV 는 저장마다 무작위, 헤더는 AAD 로 묶어 변조를 감지. 저장 직전 복호화 검증.

## 개발자용 (`dev/`)
- `core.js` 로직, `ui.js` 화면, `style.css`, `template.html`, `xlsx.full.min.js`(SheetJS, 라이선스 `SheetJS-LICENSE.txt`).
- `node dev/build.js` → `index.html` 생성(CSP 해시 자동 계산). `node dev/test-core.js` → 가상 명렬표 30명 기준 로직 테스트(44개).
- 테스트 데이터는 모두 가상입니다.
